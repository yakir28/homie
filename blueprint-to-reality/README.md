# Blueprint to Reality

Production assets for the Homie `Viral Trends` template.

- Format: 3:4 portrait
- Duration: 30 seconds
- Video model: Seedance 2.5
- Workflow: one generation using all ordered references
- Audio: disabled

The reference set is built around one fictional, ordinary suburban home. The exterior photograph is the immutable identity anchor; blueprint and transformation frames must preserve its roofline, garage, porch, windows, materials, and proportions.
