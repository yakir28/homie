# פתיחת Homie Brain ב־Obsidian

1. פתחו את Obsidian.
2. בחרו **Open folder as vault**.
3. בחרו את התיקייה `Homie Brain` שבתוך פרויקט Homie.
4. פתחו את `00 Home` והגדירו אותו כעמוד הבית.

## תוספים

מומלץ להתחיל ללא community plugins. היכולות המובנות של Backlinks, Graph view, Properties, Templates ו־Daily notes מספיקות לבסיס. מוסיפים תוסף רק כאשר יש צורך שחוזר על עצמו.

## הגדרת Templates

בהגדרות Obsidian הפעילו את תוסף הליבה **Templates** ובחרו את `99 Templates` כתיקיית התבניות.

## מוסכמה

- `[[קישור]]` מחבר רעיונות, החלטות וניסויים.
- Properties בראש כל מסמך מאפשרים סינון עתידי.
- משימה נשארת ליד ההקשר שלה; מפת הדרך מציגה רק את המשימות החשובות עכשיו.
